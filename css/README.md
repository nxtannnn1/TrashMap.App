# TrashMap Frontend – CSS

## O que é "CSS"

CSS (Cascading Style Sheets) é a linguagem responsável por definir o visual e o estilo de uma página web.  
Ela controla cores, tamanhos, espaçamentos, posicionamentos e transições, transformando estruturas simples em interfaces atraentes e responsivas.

## Por que utilizar CSS?

1. Estilo e identidade: cria uma experiência visual coesa e profissional;
2. Separação de camadas: mantém o design independente da estrutura HTML;
3. Eficiência: aplica estilos reutilizáveis em múltiplos elementos;
4. Responsividade: adapta o layout para diferentes dispositivos e tamanhos de tela;

## Boas práticas no uso de CSS

1. Organização: separar estilos em arquivos externos;
2. Nomenclatura padronizada: utilizar convenções como BEM (Block Element Modifier);
3. Modularização: evitar arquivos únicos muito extensos, preferindo módulos e componentes;
4. Performance: minimizar uso excessivo de seletores complexos e propriedades redundantes;
5. Responsividade: aplicar media queries e unidades relativas (%, rem, vh, vw);

## Conclusão

CSS é o coração visual da aplicação.  
Com boas práticas e estrutura modular, transforma a experiência do usuário em algo agradável, intuitivo e visualmente marcante.
