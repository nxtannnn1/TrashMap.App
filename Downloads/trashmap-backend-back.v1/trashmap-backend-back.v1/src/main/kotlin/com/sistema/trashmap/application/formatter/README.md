# TrashMap Backend – Formatter

## O que é "Formatter"

Formatter é responsável por padronizar a apresentação e conversão de dados, como datas, números, strings e mensagens, garantindo consistência na comunicação interna e externa.

## Por que utilizar Formatter?

1. Padronização: garante que dados sejam apresentados de forma consistente;
2. Reutilização: centraliza formatações comuns evitando duplicação de código;
3. Integração: facilita a comunicação com APIs, bancos de dados e interfaces;
4. Manutenção: alterações de formato podem ser feitas em um único ponto;

## Boas práticas no uso de Formatter

1. Clareza: nomes de métodos e classes devem indicar claramente o formato produzido;
2. Simplicidade: evitar lógica de negócio complexa dentro de formatadores;
3. Testabilidade: garantir cobertura de testes para formatos críticos;
4. Coesão: manter funções de formatação relacionadas agrupadas;

## Conclusão

Formatter garante consistência e clareza na manipulação e apresentação de dados, melhorando a integridade e a comunicação dentro do sistema.
