# TrashMap Frontend – HTML

## O que é "HTML"

HTML (HyperText Markup Language) é a linguagem de marcação que define a estrutura e o conteúdo de uma página web.  
Ela organiza textos, imagens, links, botões e todos os elementos que compõem a interface visual de um site.

## Por que utilizar HTML?

1. Fundação da Web: é o alicerce de qualquer aplicação ou site;
2. Acessibilidade: permite que navegadores e leitores de tela interpretem corretamente o conteúdo;
3. Semântica: melhora a organização e a compreensão do código;
4. SEO: otimiza o posicionamento em mecanismos de busca através de tags bem definidas;

## Boas práticas no uso de HTML

1. Semântica: utilizar tags corretas para cada tipo de conteúdo (ex: `<header>`, `<main>`, `<footer>`);
2. Estrutura clara: manter hierarquia e indentação coerentes;
3. Acessibilidade: incluir atributos `alt`, `aria` e títulos descritivos;
4. Separação de responsabilidades: evitar CSS e JS inline, mantendo o HTML apenas para estrutura;

## Conclusão

HTML é o esqueleto do frontend, fornecendo base sólida para a aplicação.  
Quando construído de forma semântica e organizada, garante clareza, acessibilidade e uma experiência de uso consistente.
